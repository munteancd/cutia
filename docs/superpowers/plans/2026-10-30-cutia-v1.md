# Cutia v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pagina de start personală a lui Cristi pe server2: Acasă (stare dintr-o privire) + Bookmarks, Unelte, 3D Print, Sport, Radio, TV, într-un shell cu meniu în stânga.

**Architecture:** Un backend mic FastAPI pe server2 adună datele (fiecare sursă cu timeout propriu + cache cu ultima valoare bună) și servește un frontend static în JS simplu (module ES, fără build), cu rutare pe `#/...` și un player audio/video care nu se oprește la schimbarea categoriei. Listele editabile (scurtături, radio, 3D, ligi) stau în `config/*.yaml`; secretele și IP-urile în `.env` pe server2.

**Tech Stack:** Python 3 (venv pe server2), FastAPI + uvicorn, httpx, paho-mqtt, PyYAML, pytest + respx; frontend vanilla JS/CSS, hls.js (cdnjs, versiune fixă) pentru TV; systemd `--user`; Caddy pentru HTTPS.

**Spec:** `docs/superpowers/specs/2026-10-30-cutia-design.md` (citește-l întreg; schițele în `docs/superpowers/specs/schite/`).
